# Shell Tool

## Purpose

| Tool | Role |
| --- | --- |
| `shell` | Execute a one-shot shell command and return its output |

## Implementations

| Implementation | Notes |
| --- | --- |
| native | Current implementation |

## Why It Matters

`shell` is the general escape hatch for command-driven workflows, but it is
also exactly the kind of capability that benefits from clearer loop policy and
approval semantics as the runtime matures.
